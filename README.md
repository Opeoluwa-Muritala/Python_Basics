# Python Basics — Example Code

A set of small, heavily commented scripts covering core Python concepts.
Each file is self-contained and runnable on its own.

| File | Topic |
|---|---|
| `01_variables_and_types.py` | Variables, data types, type conversion, f-strings |
| `02_control_flow.py` | if/elif/else, comparisons, ternary, truthy/falsy, match |
| `03_loops.py` | for, while, break/continue, loop-else, list comprehensions |
| `04_functions.py` | def, default args, *args/**kwargs, lambdas, type hints |
| `05_data_structures.py` | list, tuple, dict, set, nested structures |
| `06_error_handling.py` | try/except/else/finally, raising and custom exceptions |
| `07_classes_and_oop.py` | classes, __init__, inheritance, method overriding |
| `08_file_handling.py` | reading/writing files, CSV-style data, with statement |

## How to run

Requires Python 3.10+ (for the `match` statement in file 02).

```bash
python3 01_variables_and_types.py
python3 02_control_flow.py
# ...and so on
```

Run any file directly — no external dependencies needed, everything
uses only Python's standard library.
